## 2. Відповідь на контрольне запитання

**Запитання:** Як виконати нечутливий до регістру пошук за допомогою регулярних виразів?

**Відповідь:**
У мові Python для виконання пошуку, нечутливого до регістру (коли великі та малі літери вважаються однаковими, наприклад, "A" та "a"), використовується спеціальний прапорець **`re.IGNORECASE`** (або його скорочена версія **`re.I`**). 

Цей прапорець передається як додатковий аргумент `flags` у функції модуля `re`, такі як `re.findall()`, `re.search()`, `re.match()`, `re.sub()` тощо.


```python
import re

text = "Ласкаво просимо до NeoTerra, NEOTERRA та neoterra!"
pattern = r"neoterra"

# Використання прапорця re.IGNORECASE
matches = re.findall(pattern, text, flags=re.IGNORECASE)

print(matches) 
# Результат: ['NeoTerra', 'NEOTERRA', 'neoterra']
---
